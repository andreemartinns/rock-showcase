# Rock Showcase

Aplicação web com tema de rock, desenvolvida com foco em design moderno, interface limpa e experiência visual.

---

## 🚀 Demonstração

Acesse o projeto online:
https://SEUUSER.github.io/rock-showcase

---

## 🧠 Sobre o projeto

O Rock Showcase foi criado com o objetivo de representar a cultura do rock em um ambiente digital, utilizando um design futurista e minimalista.

O projeto apresenta uma navegação simples entre páginas, com seções organizadas e elementos visuais inspirados na estética do rock.

---

## ⚙️ Tecnologias utilizadas

* HTML
* CSS
* JavaScript

---

## 📂 Estrutura

* Página inicial
* Página de bandas
* Página sobre

---

## 🎯 Objetivo

Este projeto foi desenvolvido como parte do aprendizado em desenvolvimento web, com foco em organização de código, design e usabilidade.
